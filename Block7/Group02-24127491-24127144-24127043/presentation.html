🔍 4 Chế độ Tìm kiếm

PostgreSQL Powered

Hỗ trợ đầy đủ các cấp độ tìm kiếm từ cơ bản đến nâng cao theo slide bài giảng:

  • Basic ILIKE: Khớp chuỗi không phân biệt hoa/thường, escape triệt để !, %, _.
  • Advanced: Kết hợp cùng lúc q, category, minPrice, maxPrice, available bằng logic AND.
  • Full-Text Search (FTS): Index GIN cấu hình simple trên cả name và description, xếp hạng theo ts_rank DESC.
  • Fuzzy Trigram: Extension pg_trgm đo độ tương đồng similarity ≥ 0.3, bắt lỗi gõ sai chính tả.

📄 3 Kiểu Phân trang

UI Patterns

Cung cấp cả 3 mẫu giao diện phổ biến trên web hiện đại:

  • Numbered Pagination: Chọn số trang, có dấu ... khi nhiều trang, cuộn mượt lên đầu trang khi chuyển trang.
  • Load More Button: Bấm nút để tải thêm 10 món tiếp theo nối dồn vào danh sách hiện tại.
  • Infinite Scroll: Tự động nạp thêm dữ liệu bằng IntersectionObserver khi người dùng cuộn tới gần chân trang (rootMargin 200px).

🛡️ Chuẩn Kiến trúc CSR

Agents.md Strictly

Đảm bảo tuân thủ 100% 7 quy tắc cốt lõi:

  • Ranh giới sạch: Backend chỉ trả JSON, Frontend chỉ render bằng React SPA, không rò rỉ Secret Key.
  • Bounded Error: Lỗi nghiệp vụ (Validate/Not Found) trả HTTP 200 + ok: false. Lỗi hệ thống trả 500.
  • AbortController: Hủy các request cũ khi đổi từ khóa hoặc bộ lọc, loại bỏ race condition.
  • Client vs Server Scope: Banner thông báo rõ số món đang lọc trên trình duyệt vs tổng số trên Database.

Full Stack Details

Dự án được xây dựng với cấu trúc tách biệt hoàn toàn giữa Client (Frontend SPA) và Server (Backend REST API) theo đúng chuẩn doanh nghiệp:

🖥️ BACKEND REST API

  • Runtime: Node.js (ES Modules), Express ^4.19.2, TypeScript ^5.5.4.
  • Database ORM: Prisma ^5.14.0 với 2 kênh kết nối:
    • DATABASE_URL: Transaction pooler port 6543 (IPv4 pgbouncer) cho runtime query.
    • DIRECT_URL: Session pooler port 5432 phục vụ migration / raw DDL.
  • Bảo mật truy vấn: Tham số hóa 100% bằng Prisma.sql ($1, $2, ...), tuyệt đối không nối chuỗi (Zero SQL Injection).
  • Cơ chế tự phục hồi: Module withDbRetry tự động thử lại 2 lần khi pooler đóng kết nối ngầm (P1001, P1017).
  • Phân tầng lỗi: Bounded Error Handling (Rule 3) trả HTTP 200 kèm envelope JSON { ok: false, error: { code: 'VALIDATION_FAILED', fields } }.

🌐 FRONTEND SPA (CSR)

  • Framework: React ^18.3.1 + Vite ^5.4.2 + TypeScript.
  • Routing: React Router DOM ^6.26.2 với Deep link fallback.
  • Đồng bộ URL: Đọc và ghi toàn bộ tiêu chí (mode, q, category, minPrice, maxPrice, available, page, uiMode) lên URL search params.
  • Single API Client: Lớp ApiService duy nhất đóng gói toàn bộ lệnh gọi fetch, xử lý CORS, map lỗi tiếng Việt.
  • Hiệu năng UI: IntersectionObserver với rootMargin 200px cho Infinite Scroll; client-side cache & deduplication theo Dish ID.

🗄️ CƠ SỞ DỮ LIỆU POSTGRESQL TRÊN SUPABASE (CLOUD)

pg_trgm Extension

Kích hoạt extension tính độ tương đồng chuỗi 3 ký tự (Trigram). Ngưỡng công bố similarity ≥ 0.3 phục vụ Fuzzy Search.

GIN Index Full-Text Search

Tạo GIN index Dish_fts_idx sử dụng cấu hình chuẩn 'simple' đồng nhất trên cả coalesce(name, '') || ' ' || coalesce(description, '').

B-Tree Indexing

Chỉ mục B-Tree trên category, price, available, createdAt đảm bảo tốc độ lọc hàng nghìn bản ghi chỉ trong vài mili-giây.
